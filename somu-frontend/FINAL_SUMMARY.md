## 🔄 Data Flow

```
User Interface (Browser)
       ↓ (Click, Type, Filter)
React Frontend (React Components)
       ↓ (Axios HTTP GET)
Spring Boot Backend (REST API)
       ↓ (JPA Query)
Database (H2/MySQL)
       ↓ (Results)
Spring Boot Backend
       ↓ (JSON Response)
React Frontend
       ↓ (Display)
User sees products
```
